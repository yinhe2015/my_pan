# 私人云盘 - 管理

## linux 服务管理命令 (仅限linux系统)
```bash

systemctl --user start pan-service # 启动
systemctl --user stop pan-service # 停止
systemctl --user restart pan-service # 重启

systemctl --user status pan-service # 查看运行状态
systemctl --user enable pan-service # 开启开机自启
systemctl --user disable pan-service # 关闭开机自启
journalctl --user -u pan-service -f # 查看实时日志
journalctl --user -u pan-service # 查看所有日志

systemctl --user daemon-reload # 重新加载服务配置文件 (修改.service文件后必须执行)
systemctl --user restart --force pan-service # 强制重启
```
